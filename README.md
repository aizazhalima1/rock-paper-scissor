<h1> Rock Paper Scissors </h1>
<p>A full-stack Rock Paper Scissors game implemented using JavaScript. Players can compete against a computer opponent in a series of rounds, with the game ending after ten rounds. The player and computer points are tracked, and the winner is announced at the end.</p>
<h2> Features </h2>

  <ul style="list-style-type:⚫">
    <li><strong>Interactive Gameplay : </strong>Player chooses moves by clicking buttons.</li>
    <li><strong>Real-time Score Tracking : </strong>Points are updated dynamically after each round.</li>
    <li><strong>Game End Notification: </strong>The game displays a message indicating the winner after ten rounds.</li>
    <li><strong>Responsive UI: </strong>A user-friendly interface to enhance the gaming experience.</li>
  </ul>





  <h2>Technologies Used</h2>
  <ul style=list-style⚫>
    <li><strong>Frontend:</strong>HTML,CSS,JavaScript</li>
    <li><strong>Backend:</strong>Node.js</li>
    <li><strong>API:</strong>Built-in HTTP server to interact with the frontend</li>
  </ul>

<h2>How to Play</h2>
<ol>
<li>Click the "Start" button to begin the game.</li>
<li>Choose one of the options: Rock, Paper, or Scissors by clicking the respective button.</li>
<li>The game will automatically track the score and announce the winner after ten rounds.</li>
<li>Click "Start" again to restart the game.</li>
</ol>
